Сводка в канал — шапки и фото

Каждый пост берёт следующую шапку и картинку по кругу. Можно писать как блогер; {h} подставится как «4» (окно в часах). То же самое есть в боте: Админка → Шаблоны канала.

    📸 Фото постов в канал

    В пост уходит одно фото: набор листается от поста к посту — обложкой по очереди бывает каждое. Альбома нет: он валил все загруженные фото в один пост. Пусто — берутся картинки из комплекта.

    jpg, png, webp — до 12 МБ

    🗞 Фото дневного дайджеста

    Свои картинки для вечернего выпуска. Если пусто — дайджест возьмёт фото постов. Карусель та же.

    📣 Каналы

      id — это число вида -1001234567890. Бот должен быть админом канала (права на публикацию). Сменить канал можно и пересылкой поста боту — как раньше.

      🧪 Публикация

      Включён — пост ждёт вашего «✅ Опубликовать» в боте. Выключен — уходит в канал сразу.

      🕒 Частота сводки

      Пост раз в N часов: окно поста — эти же N часов, а блок анализа внутри поста — четверть окна (раз в 4 ч → по часу, раз в 1 ч → по 15 минут). Расписание применяется сразу, перезапуск не нужен.

      🤖 Промты для ИИ

      Инструкции, по которым ИИ пишет шапку поста в канал и текст дневного дайджеста. В поле уже стоит стандартный промт — правьте прямо в нём; «Вернуть шаблон» очищает поле и снова включает встроенный текст. Пустое поле = стандарт, свои цифры и факты ИИ по-прежнему берёт из сводки.
