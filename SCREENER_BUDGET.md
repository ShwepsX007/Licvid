# Whale Alert: стоимость, ограничения и фактическое покрытие

**Важное ограничение:** бесплатный Alchemy даёт 30 млн CU за месяц на всё приложение, не на каждую сеть. Этот скринер по умолчанию резервирует для себя не больше **10 млн CU**. Остальные 20 млн — запас для других функций и скачков потребления. Это не проверка фактического остатка Alchemy в кабинете: у сервера нет авторизации для просмотра биллинга. Для точного общего остатка необходимо сверить расход приложения в Dashboard; обещать, что «хватит на месяц», не зная остальных запросов, нельзя.

## Арифметика на 30 суток

- 1 опрос/мин = 43 200 опросов **каждой** сети/месяц; 1/10 мин = 4 320; 1/60 мин = 720. Если опрашивать 13 сетей, это соответственно 561 600 / 56 160 / 9 360 запусков, но не равное число RPC-запросов.
- Тарифная таблица Alchemy: `eth_blockNumber` = 10 CU, `eth_getLogs` = 60 CU, `alchemy_getAssetTransfers` = 120 CU, `eth_getBlockByNumber` = 20 CU. Стоимость запроса batch складывается из стоимости его частей.
- Наш EVM-режим «только известные биржи»: 6 запросов на высоту + **как минимум** 12 `eth_getLogs` на входы/выходы (больше на длинных диапазонах), 4 сети × 8 кошельков × 2 направления = 64 `alchemy_getAssetTransfers` на нативные переводы; итого **не меньше 60 + 720 + 7680 = 8 460 CU/опрос**. За месяц при опросе раз в час нижняя оценка **6 091 200 CU**; каждые 10 минут — **36 547 200 CU** (выше Free). При часовых окнах Arbitrum может потребовать >1 порции логов, а активный адрес — несколько страниц transfer API: реальный расход выше нижней оценки.
- Поэтому по умолчанию **1 раз в 60 минут**, а не в 1 или 10 минут. Порог 10 млн CU/мес жёсткий для запросов именно этого опросчика: перед **каждым** RPC-запросом резервируется его CU и счётчик пишется на диск. По достижении лимита опрос приостанавливается; курсоры не перепрыгивают через необработанные блоки. Если расходы других приложений на том же ключе превысили запас 20 млн CU, общей гарантии всё равно нет.
- «Все переводы»: только чтение каждого блока Arbitrum при номинальных 250 мс × 20 CU за блок = **207 360 000 CU за 30 дней**, даже без токенов, других сетей, цен и повторов. Увеличение интервала не меняет число блоков, если их не пропускать. При Free полный режим **недоступен**, админка его не включает.

## Реализовано сейчас

| Сеть | Известные EVM-адреса бирж | Нативная монета |
| --- | --- | --- |
| Ethereum | Transfer USDT/USDC/DAI/WBTC | ETH через Transfers API |
| BNB Chain | Transfer USDT/USDC/DAI/BTCB | Нет: Transfers API здесь не заявлен |
| Polygon | Transfer USDT и два варианта USDC | POL через Transfers API (только если есть живая цена POL_USDT) |
| Arbitrum | Transfer USDT/USDC/DAI/WBTC | ETH через Transfers API |
| Base | Transfer USDC | ETH через Transfers API |
| HyperEVM | Transfer USDC; **не** HyperCore | HYPE не включён, нет подтверждённой цены в market_feed |

Это *не* полная история движения всех бирж: список из восьми EVM-адресов мал, биржи меняют адреса, у разных сетей набор кошельков отличается. При первой загрузке сохраняется текущая высота каждой сети, старая история не запрашивается. События, не привязанные к включённым контрактам или кошелькам, не появятся. USD для нестабильных активов без котировки не выдумывается.

**Остальные запрошенные сети — пока НЕ подключены к ленте:** Solana, Bitcoin, Bitcoin Cash, Litecoin, Tron, Sui, Dogecoin. Для них нельзя использовать 0x-адреса Ethereum: нужны подтверждённые адреса бирж в формате каждой сети и собственные адаптеры. Bitcoin/BCH/LTC/DOGE — UTXO (выход может быть сдачей), Solana и Tron используют другие модели, а Sui JSON-RPC прекращён 25 сентября 2026 года — требуется Sui gRPC. Не выдавать отсутствие данных в этих сетях за отсутствие китов.

### Что делать для расширения

1. Собрать проверенные списки биржевых адресов **по каждой сети**, с источником и датой проверки.
2. Реализовать соответствующие CEX-indexed адаптеры только если API на этой сети позволяет искать по адресу без полного обхода блоков; иначе нужны webhook/indexer/платный тариф.
3. До запуска проверять реальный ключ и статус возможностей сети; отсутствие ключа/разрешения не должно считаться нулём транзакций.

Результат API `/api/screener/whales` содержит `poller`: интервал, бюджет, зарезервированные CU, курсоры, ошибки и явно помеченные непокрытые сети. Это оценки **локального** расхода, а не данные биллинга Alchemy. Настройка интервала/потолка — админ-панель. Ключ Alchemy ни в одном ответе API не выводится.
