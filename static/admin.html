📣 Рекламные посты

Свой текст и фотография, а дальше — куда и когда отправить: в бота, в каналы и баннером на сайте (главная, терминал, дайджест, сводка по часам). Объявление уйдёт само в выбранное время, а через выбранный срок снимется: баннеры пропадут, посты в каналах удалятся.

Картинка — фото с кликом по ссылке. HTML — вставьте код партнёрки, iframe или верстку, он покажется в том же месте, где обычно картинка.

🎛 Баннер на сайте

Сколько секунд стоит одна картинка, насколько плавно они сменяются и показывать ли все акции сразу сеткой. Крестика у баннера нет вовсе: снять объявление может только админка, а посетитель видит акцию всю заданную ей срок. Настройки применяются на следующем показе страницы — без перезапуска сервера.

секунд (2…120). При одном объявлении таймер не нужен — слайд стоит до истечения срока.

миллисекунды на затухание. 0 — резкая смена; система «уменьшить движение» в браузере включает 0 сама.

Где показывать акцию — отмечают в самой записи: 🌐 Главная, 📈 Терминал (под графиком, скрывается для зарегистрированных), 📰 Дайджест и 🕘 Сводка по часам — баннер над списком.

Сводка в канал — шапки и фото

Каждый пост берёт следующую шапку и картинку по кругу. Можно писать как блогер; {h} подставится как «4» (окно в часах). То же самое есть в боте: Админка → Шаблоны канала.

    📸 Фото постов в канал —

    В пост уходит одно фото, и набор листается по кругу без повторов: обложкой идёт то фото, которое дольше всех не выходило, поэтому одинаковые картинки подряд не повторяются. Файлов можно выбрать сразу много — сохранятся все. Альбома нет: он валил все загруженные фото в один пост. Пусто — берутся картинки из комплекта.

    Рандом — каждый круг в новом случайном порядке (как раньше). Очередь — строго 1,2,3…N, снова 1,2,3… — удобно, когда загрузили пачку и хочется, чтобы каждая показалась по разу.

    jpg, png, webp — до 12 МБ каждое, можно выбрать пачку
    🗞 Фото дневного дайджеста —

    Свои картинки для вечернего выпуска: тот же круг без повторов. Если пусто — дайджест возьмёт фото постов. Можно выбрать сразу много файлов.

    Рандом — каждый круг в новом случайном порядке. Очередь — 1,2,3…N по кругу.

    📣 Каналы

      id — это число вида -1001234567890. Бот должен быть админом канала (права на публикацию). Сменить канал можно и пересылкой поста боту — как раньше.

      🧪 Публикация

      Включён — пост ждёт вашего «✅ Опубликовать» в боте. Выключен — уходит в канал сразу.

      🕒 Частота сводки

      Пост раз в N часов: сводка почасовая — по строке на каждый из N последних завершённых часов (вплоть до 24). Расписание применяется сразу, перезапуск не нужен.

      Выключено — бот не шлёт сводки автоматически и по кнопке «Сводка в канал» только по force. Защита от дубля после рестарта — по логу.
